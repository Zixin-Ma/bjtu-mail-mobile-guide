# BJTU 邮箱手机配置指南

北京交通大学 MIS 邮箱的手机绑定图文教程，包含客户端专用密码生成、iOS 自带「邮件」和网易邮箱客户端的配置步骤。

**[在线阅读教程](https://zixin-ma.github.io/bjtu-mail-mobile-guide/)**

## 使用

- 手机和电脑均可浏览，点击截图可放大查看。
- 下载 [`index.html`](./index.html) 后，可直接用浏览器打开。图片、样式和脚本均已内嵌，无需安装依赖。
- 官方配置依据见教程中的[参考资料](https://zixin-ma.github.io/bjtu-mail-mobile-guide/#references)。

## 维护

修改 `index.html` 后推送到 `main` 分支，GitHub Pages 会自动更新线上教程。更新截图时，请使用占位信息，并同步校准红框和箭头。
